# Pi çekirdeği

Pichamber, varsayılan olarak Pi çekirdeğini uygulama içinde çalıştırır. Bu sayfa, ayrı bir OpenCode sürecine bağlanma sorunlarını belgelemez — o yol Pichamber masaüstü ürününde kullanılmaz.

Sohbet yanıt vermiyorsa:

- Pi’nin `~/.pi/agent` altında yapılandırıldığını kontrol edin
- Gerekirse uygulamayı yeniden başlatın
- Sağlayıcı kimlik bilgilerinin Settings → Providers bölümünde kayıtlı olduğundan emin olun

Kalan OpenCode süreç yolu yalnızca `OPENCHAMBER_KERNEL=opencode` ile geri yüklenir ve masaüstü varsayılanı değildir.
