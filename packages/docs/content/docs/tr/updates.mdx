# Güncellemeler

Pichamber'ı nasıl güncelleyeceğiniz, onu nasıl kurduğunuza bağlıdır. Her durumda geçerli sürümünüzü **Ayarlar → Pichamber → About** bölümünden görebilirsiniz.

## Masaüstü uygulaması

Masaüstü uygulaması güncellemeleri GitHub sürümlerinden kontrol eder. Bir güncelleme varsa Pichamber bunu söyler, siz seçince indirir ve bir sonraki yeniden başlatmada kurar. Kontrol sizdedir. Hiçbir şey sizin onayınız olmadan kurulmaz.

## Web / CLI

CLI kurduysanız güncelleme işlemini **About** içindeki kontrol ve güncelle düğmeleriyle ya da terminalden yapabilirsiniz:

```bash
openchamber update
```

Pichamber nasıl kurulduğunu algılar. npm, pnpm, yarn ya da bun olabilir. Sizin için doğru güncellemeyi çalıştırır.

## OpenCode sunucusu

Pichamber ve OpenCode ayrı ayrı güncellenir. Yeni bir OpenCode sürümü varsa Pichamber onu güncellemenizi önerir ve ardından sunucuyu yeniden başlatır. O sunucunun nasıl yönetildiği için [OpenCode Server](/opencode-server/) sayfasına bakın.
