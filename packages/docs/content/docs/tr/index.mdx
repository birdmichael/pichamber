# Pichamber Belgeleri

Pichamber, terminalinizde çalışan AI kodlama agent'ı OpenCode'un etrafındaki görsel çalışma alanıdır. Komut satırında yaşamaktansa, o işi izleyip yönlendireceğiniz bir ekran verir.

Bu dokümanları şunlar için kullanın:

- çalışma biçiminize uygun uygulamayı kurmak
- güvenli uzaktan kullanım için Pichamber'ı açmak
- görünümü özelleştirmek ve yaygın sorunları gidermek

## Pichamber ne için

Pichamber, AI kodlamanın bir kontrol odasından fayda gören kısımları içindir. Branch'lenmiş oturumlar, diff inceleme, terminal yönetimi, araç ilerlemesini izleme, project action'ları çalıştırma ve agent çalışırken tüm tahtayı görünür tutma.
