# 공급자, 모델, 에이전트

OpenChamber가 무언가를 하려면 먼저 최소한 하나의 AI 공급자가 연결되어 있어야 합니다. 이 페이지에서는 공급자 연결, 모델 선택, 내장 Pi 에이전트가 어떻게 동작하는지를 다룹니다.

## 공급자 연결하기

1. **Settings → Providers**를 엽니다.
2. **Add provider** 메뉴를 열고 아직 연결되지 않은 공급자를 선택합니다.
3. 공급자에 따라 다음 두 가지 방법 중 하나로 로그인합니다.
   - **API key** — 키를 붙여넣고 저장합니다.
   - **Sign-in (device flow)** — OpenChamber가 링크와 짧은 코드를 표시합니다. 링크를 열고 코드를 입력한 뒤 승인합니다. 나머지 연결은 OpenChamber가 알아서 마무리합니다.

공급자가 연결됨으로 표시되면 해당 모델을 채팅에서 사용할 수 있습니다.

연결을 해제하려면 공급자를 열고 로그인을 제거하도록 선택합니다.

## 모델 선택하기

작업하는 위치에서 모델을 선택합니다.

- 채팅에서는 메시지 바의 모델 선택기로 해당 세션의 공급자와 모델을 설정합니다
- **Settings → Session Defaults**에서 기본 모델과 thinking을 설정합니다

## 내장 에이전트

Pichamber는 내장 에이전트(`pi`) 하나를 사용합니다. Pi에서는 **Settings → Agents**가 숨겨집니다. 거기서 추가 에이전트나 성격을 만들지 않습니다.

대신 다음을 사용하세요.

- **모델과 thinking** — 채팅 메시지 바, 또는 **Settings → Session Defaults**
- **Plan** — 같은 에이전트의 세션 모드입니다. **Settings → Feature Plugins**에서 설치하고 켜면 입력창에 **Agent / Plan**이 나타납니다.
- **Subagents** — Feature Plugins **Subagents**와 `/run`으로 추가 워커를 실행합니다. Settings의 추가 에이전트가 아닙니다.

남은 OpenCode 커널(`OPENCHAMBER_KERNEL=opencode`)에서는 **Settings → Agents**가 이름 있는 에이전트를 만들고 편집하는 곳입니다.

## 로그인 정보가 저장되는 위치

공급자 로그인 정보는 OpenChamber가 아니라 OpenCode에 저장되므로 OpenCode CLI와 공유됩니다. 같은 공급자를 여러 곳에 설정하면 가장 구체적인 설정이 우선합니다. 프로젝트별 설정이 개인 설정을 덮어씁니다.
